「来店したけど次の予約がない」「しばらく来ていない」お客様への声がけは、これまでスタッフが個別に行う必要があった。 このシステムでは、サロンボード（予約・売上）と LINE を連携させ、お客様の状況に応じたメッセージを自動で送信する。 スタッフは接客・技術に集中できる。

02

お客様データの統合方法

LINE と サロンボードは別々のシステムのため、「どのLINE友だちが、どの予約のお客様か」を自動的に突き合わせる必要がある。 これを電話番号照合によって実現している。

サロンボード
予約データ（電話番号付き）
→
電話番号で照合
毎日22:18 自動実行
→
LINE友だちシート
LINE UID + 電話番号
→
LINE UID を紐付け
→ メッセージ送信可能に
データ元 持っている情報 照合キー
サロンボード（予約データ） お客様名・予約日時・メニュー・担当スタッフ・電話番号 電話番号
LINE友だちシート LINE UID・最終来店日・タグ（メニュー）・店舗名
照合のルール：
電話番号の先頭ゼロの有無・ハイフンの違いを自動で正規化して照合します（例：「090-1234-5678」と「09012345678」は同一として扱う）。 照合に成功した顧客のみ、LINEへのメッセージ送信が有効になります。

店舗・メニューの自動判定

統合されたデータをもとに、どの店舗のどのメニューを使ったかを自動で判定し、配信内容・予約URLを切り替えます。

誤送信ゼロの安全設計

リスク 対策 状態
同じお客様への二重送信 「送信済みリスト」で管理。顧客×シナリオ×日付の組み合わせで重複ゼロを保証 対策済み
予約済みの方への勧誘メッセージ 配信前に予約データと照合。次回予約が確認できた方には「おかえりなさい」等を送らない 対策済み
間違ったHPB URLの送信 メニュー・店舗から予約URLを自動判定。マツエクは常にLUMISS藤沢HPBへ固定 対策済み
システムエラーの誤配信 エラーはログのみに記録。LINE公式アカウントからは絶対に送信しない 対策済み
